Claude Desktop / Claude Code 設定 (MCP サーバー)

Anthropic の Model Context Protocol (MCP) に対応しています。 claude_desktop_config.json に以下の設定を追加すると、Claude が Wiki の検索・参照・編集を実行できるようになります。

claude_desktop_config.json 
{{ claudeConfigJson }}
利用可能なツール:
  • wiki_search: キーワードで Wiki 記事を検索
  • wiki_get_page: 指定ページの最新 Markdown 原文と SHA を取得
  • wiki_list_pages: カテゴリ別ページ一覧を取得
  • wiki_save_page: ページを編集して GitHub へコミット（Discord ユーザーとして署名）
