TORO Wiki 記事編集ガイド

TORO Server Wiki は、誰でも情報を追加・編集して改善に参加できます。
編集方法は「Discord ログインによるWeb編集」と「GitHub での編集」の2通りがあります。

おすすめ

1. ブラウザ上で直接編集 (Discord 連携)

Discord アカウントでログインするだけで、ブラウザ上の専用エディタから Markdown を直接編集・即座に保存できます。

  • 右上の「Discord ログイン」または記事の「このページをWeb編集」を押す
  • Discord 認証を許可する (TORO Server 公式 Discord の参加権限を自動確認)
  • Windows XP 風エディタでプレビューを見ながら編集し、「保存してコミット」を押す

開発者・PR向け

2. GitHub から編集

GitHub アカウントをお持ちの方は、リポジトリの Markdown ファイルを直接編集して Pull Request (変更提案) を作成できます。

  • 各記事の上部やサイドバーにある「GitHub で編集」リンクをクリック
  • GitHub 上の鉛筆アイコンで Markdown を編集
  • 変更内容の要約を入力し、Pull Request を送信 (管理者が確認後反映)
GitHub リポジトリを開く

📝 編集のルール・ヒント

  • 記事はすべて Markdown 形式です。見出し (##) やリスト (-) が使えます。
  • 他の Wiki 記事へのリンクは [記事名](../01_Guide/ルール.md) のように記述します。
  • 荒らし行為や規約違反となる文章の投稿は禁止されています。すべての編集履歴は記録されます。
